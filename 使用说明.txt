============================================
     H3MegaDesc 插件 使用说明
============================================

一、插件功能
----------------------------------------------
本插件扩展《魔法门之英雄无敌III》生物信息窗口：

1. 窗口高度扩展
   - 默认从 311 像素扩展到 383 像素
   - 窗口固定宽度为 298 像素
   - 窗口内所有元素（头像、属性、按钮、描述等）整体下移，适配扩展后的布局
   - 可通过 MegaDesc.ini 的 WindowHeight 项调整目标高度

2. 背景图扩展
   - 当前默认底图为 298×383 的 bv_bg.pcx
   - 背景加载器支持标准 8 位索引 PCX 和 24 位三平面 PCX
   - 插件将背景图量化到游戏调色板后替换窗口背景，覆盖整个窗口区域

3. 按钮图像扩展
   - 确认/解雇/魔法书三个按钮的图像与 298×383 窗口同步
   - 按钮边框（金框）和图标合成到 66×32 像素，清晰锐利
   - 确认按钮位于底部；解雇和魔法书不会同时出现，二者共用确认按钮上方的同一位置
   - 按钮按下效果正常保留

4. 描述文本区域扩展
   - 当前 298×383 底图使用 TextHeight=105 的描述区域
   - 可选支持鼠标滚轮滚动，默认关闭
   - 可选支持跨行彩色文本补丁，默认关闭

5. 战斗价值显示
   - 生物名称下方第二行显示单只生物的战斗价值
   - 战斗中若能唯一匹配当前 stack，括号内显示队首单只按剩余 HP 折算后的战斗价值

6. 窗口位置约束
   - 扩展后窗口底部不会超出屏幕范围
   - 窗口自动贴边吸附


二、文件说明
----------------------------------------------
MegaDesc.dll      - 主插件 DLL（本体）
MegaDesc.ini      - 配置文件（可调整各项参数）
pcx/              - 背景和按钮 PCX 素材目录
  bv_frmL.pcx     - 确认按钮金框（66×32）
  bv_ok0~3.pcx    - 确认按钮图标（4帧：普通/按下/高亮/禁用）
  bv_frmS.pcx     - 解雇/魔法书按钮金框（66×32）
  bv_ds0~3.pcx    - 解雇按钮图标
  bv_sp0~3.pcx    - 魔法书按钮图标
  bv_bg.pcx       - 当前背景图（298×383，标准 8 位索引 PCX）


三、安装方法
----------------------------------------------
1. 确认已安装 HD Mod（插件依赖 HD Mod 加载机制）
2. 将本目录（包含 MegaDesc.dll、MegaDesc.ini、pcx\）复制到：
   <游戏目录>\_HD3_Data\Packs\大描述框\
   目录结构应为：
   _HD3_Data\Packs\大描述框\MegaDesc.dll
   _HD3_Data\Packs\大描述框\MegaDesc.ini
   _HD3_Data\Packs\大描述框\pcx\bv_bg.pcx
   _HD3_Data\Packs\大描述框\pcx\bv_*.pcx
3. 启动 HD Mod 启动器，进入"插件"页面
   - 在"未加载"列表中找到"大描述框"（或 MegaDesc）
   - 点击"→"按钮，将其添加到"已加载"列表
4. 启动游戏，插件自动生效


四、配置说明（ MegaDesc.ini ）
----------------------------------------------
[Layout]
WindowHeight=383           ; 目标窗口高度，默认 383
FightValueYOffset=19       ; 战斗价值行相对名称行的 Y 偏移
ConfirmBtnMarginLeft=215      ; 确认按钮金框左上角距窗口左侧，默认 215
ConfirmBtnMarginBottom=72     ; 确认按钮金框左上角距窗口底部，默认 72
DismissBtnMarginLeft=215      ; 解雇按钮金框左上角距窗口左侧，默认 215
DismissBtnMarginBottom=122    ; 解雇按钮金框左上角距窗口底部，默认 122
SpellBtnMarginLeft=215        ; 魔法书按钮金框左上角距窗口左侧，默认 215
SpellBtnMarginBottom=122      ; 魔法书按钮金框左上角距窗口底部，默认 122
UpgradeBtnMarginLeft=230   ; 升级按钮金框左上角距对话框左侧，默认 230
UpgradeBtnMarginBottom=181 ; 升级按钮金框左上角距对话框底部，默认 181

DescY=248                  ; 描述文本框 Y 坐标，默认 248
TextHeight=105             ; 描述文本高度，默认 105
TextWidth=200             ; 描述文本宽度，默认 200
DescXOffset=5              ; 描述文本 X 偏移，默认 5

[Logging]
DisableLog=0               ; 1=禁用日志，0=启用日志

[Format]
LabelFightValue=战斗价值   ; 战斗价值标签文字

[Features]
EnableRightClickScroll=0   ; 右键魔法描述框滚轮翻页：0=关闭，1=启用
EnableTextColorFix=0       ; 滚动文本跨行颜色补丁：0=关闭，1=启用


五、兼容性
----------------------------------------------
- 仅支持 HD Mod 环境
- 支持战斗、冒险、城镇三种生物信息窗口
- 支持有/无解雇按钮的场景
- 支持有/无魔法书按钮的场景


六、卸载方法
----------------------------------------------
删除 _HD3_Data\Packs\大描述框\ 整个目录即可。


七、已知问题
----------------------------------------------
- 背景图替换依赖 id=200 控件存在；若游戏更新导致控件结构变化，插件可能失效
- 按钮图像需要 pcx 目录下的素材；若素材缺失，对应按钮将使用原版图像


八、日志
----------------------------------------------
运行日志保存在：
<游戏目录>\_HD3_Data\Packs\大描述框\MegaDesc_YYYYMMDD_HHMMSS.log

设置 DisableLog=1 可禁用日志，减少磁盘写入。
