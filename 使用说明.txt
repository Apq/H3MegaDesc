============================================
     H3MegaDesc 插件 使用说明
============================================

一、插件功能
----------------------------------------------
本插件扩展《魔法门之英雄无敌III》生物信息窗口：

1. 窗口高度扩展
   - 默认从 311 像素扩展到 487 像素
   - 窗口内所有元素（头像、属性、按钮、描述等）整体下移，适配扩展后的布局
   - 可通过 MegaDesc.ini 的 WindowHeight 项调整目标高度

2. 背景图扩展
   - 自动将 24-bit 背景图（bg.pcx）量化到游戏调色板，生成 298×487 的大背景图
   - 替换窗口背景，完全覆盖扩展区域

3. 按钮图像扩展
   - 确认/解雇/魔法书三个按钮的图像与加高后的窗口同步
   - 按钮边框（金框）和图标合成到 66×32 像素，清晰锐利
   - 按钮按下效果正常保留

4. 描述文本区域扩展
   - 描述文本框高度从默认 120 扩展到 207 像素
   - 支持鼠标滚轮滚动
   - 支持跨行彩色文本

5. 窗口位置约束
   - 扩展后窗口底部不会超出屏幕范围
   - 窗口自动贴边吸附


二、文件说明
----------------------------------------------
MegaDesc.dll      - 主插件 DLL（本体）
MegaDesc.ini      - 配置文件（可调整各项参数）
pcx/              - 按钮素材目录
  bv_frmL.pcx     - 确认按钮金框（66×32）
  bv_ok0~3.pcx    - 确认按钮图标（4帧：普通/按下/高亮/禁用）
  bv_frmS.pcx     - 解雇/魔法书按钮金框（66×32）
  bv_ds0~3.pcx    - 解雇按钮图标
  bv_sp0~3.pcx    - 魔法书按钮图标
  bg.pcx          - 背景图（建议 298×487，24-bit PCX）


三、安装方法
----------------------------------------------
1. 确认已安装 HD Mod（插件依赖 HD Mod 加载机制）
2. 将本目录（包含 MegaDesc.dll、MegaDesc.ini、pcx\）复制到：
   <游戏目录>\_HD3_Data\Packs\大描述框\
   目录结构应为：
   _HD3_Data\Packs\大描述框\MegaDesc.dll
   _HD3_Data\Packs\大描述框\MegaDesc.ini
   _HD3_Data\Packs\大描述框\pcx\bg.pcx
   _HD3_Data\Packs\大描述框\pcx\bv_*.pcx
3. 启动游戏，插件自动加载


四、配置说明（ MegaDesc.ini ）
----------------------------------------------
[Layout]
WindowHeight=487           ; 目标窗口高度，默认 487
BtnMarginBottom=40         ; 确认按钮距底边距，默认 40
DismissBtnMarginBottom=90  ; 解雇按钮距底边距，默认 90
SpellBtnMarginBottom=140   ; 魔法书按钮距底边距，默认 140
DescY=257                  ; 描述文本框 Y 坐标，默认 257
TextHeight=207             ; 描述文本高度，默认 207
TextWidth=258             ; 描述文本宽度，默认 258
DescXOffset=0              ; 描述文本 X 偏移，默认 0

[Log]
DisableLog=0               ; 1=禁用日志，0=启用日志


五、兼容性
----------------------------------------------
- 仅支持 HD Mod 环境
- 支持战斗、冒险、城镇三种生物信息窗口
- 支持有/无解雇按钮的场景
- 支持有/无魔法书按钮的场景


六、卸载方法
----------------------------------------------
删除 _HD3_Data\Packs\大描述框\ 整个目录即可。


七、已知问题
----------------------------------------------
- 背景图替换依赖 id=200 控件存在；若游戏更新导致控件结构变化，插件可能失效
- 按钮图像需要 pcx 目录下的素材；若素材缺失，对应按钮将使用原版图像


八、日志
----------------------------------------------
运行日志保存在：
<游戏目录>\_HD3_Data\Packs\大描述框\MegaDesc_YYYYMMDD_HHMMSS.log

设置 DisableLog=1 可禁用日志，减少磁盘写入。
